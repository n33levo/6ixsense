# 6ixsense

Futuristic “under construction” landing page with animated typography, orbital visuals, and a procedurally generated cosmic soundscape.

## Preview locally

Open `index.html` in any modern browser (Chrome, Edge, Safari, Firefox). Interact with the page once to unlock audio playback—most browsers require a user gesture before sound can start.

## Publish on GitHub Pages

1. Create the repository on GitHub:  
   `gh repo create 6ixsense --public --source=. --remote=origin --push`
2. In the repository’s **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch, and the `/ (root)` folder.
3. After GitHub Pages finishes building, your site will be available at `https://<your-username>.github.io/6ixsense/`.

## Audio notes

The background audio uses the Web Audio API to synthesize evolving pads and low-frequency cosmic rumbles in real time—no third-party assets required.
